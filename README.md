# Healthcare Analytics Dashboard

## Project Overview
This project analyzes healthcare data to uncover insights related to patient demographics, hospital performance, medical conditions, admissions, and financial metrics. The analysis was performed using SQL, Python, and Power BI to demonstrate end-to-end data analytics skills.

## Objectives
- Analyze patient demographics and healthcare utilization patterns.
- Identify trends in medical conditions and admissions.
- Evaluate hospital performance using revenue and operational metrics.
- Build interactive Power BI dashboards for data-driven decision-making.

## Tools & Technologies
- SQL (MySQL Workbench) – Data querying and analysis
- Python (Pandas) – Data cleaning and feature engineering
- Power BI – Interactive dashboard creation
- VS Code – Python development

## Dataset Information
- Dataset: Healthcare Dataset
- Number of Records: 10,000 patient records
- Key Features:
  * Age
  * Gender
  * Medical Condition
  * Hospital
  * Billing Amount
  * Insurance Provider
  * Admission Type
  * Test Results
  * Date of Admission
  * Discharge Date

## Python Data Preparation
- Loaded and explored the dataset using Pandas.
- Checked for missing values and duplicate records.
- Converted date columns into datetime format.
- Created a new feature: Length of Stay.
- Categorized patients into Age Groups.
- Exported the cleaned dataset for Power BI analysis.

## SQL Analysis Performed
- Analyzed revenue generated by hospitals.
- Identified the most common medical conditions.
- Examined admission type distributions.
- Evaluated insurance provider trends.
- Explored patient demographic patterns.
- Calculated average billing amounts.
